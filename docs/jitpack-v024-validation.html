重建记录

首次 latest 镜像构建在解析 Kotlin Gradle plugin 时遇到 Maven Central HTTP 429，未生成产物。登录并清除失败构建缓存后，同一标签的 legacy 镜像构建状态变为 ok，下载和真实远端消费验证均通过。build.log 下载端点仍返回首次失败日志，因此它不能作为成功构建的证据；成功结论依据带正确提交的 API 状态、发布产物核对和实际消费结果。

固定基线与边界

本地与远端消费验证运行在 macOS arm64 / Microsoft JDK 21.0.12.1。Gradle 8.14.3、Kotlin 2.2.0、ProGuard 7.7.0。新增依赖样例使用 Compose 1.8.2 / JVM 目标 21，对齐 FloatClock；Coil 远端样例使用 Compose 1.9.3 / JVM 目标 17。发布插件的字节码目标为 JDK 17。

本次没有修改 FloatClock，也没有验证其完整 GUI 或原生安装包。OSHI 的 macOS 原生调用经过真实运行；Windows COM / PDH 与 Linux 原生路径尚未在对应系统上执行。跨平台 CI 结果不作为此次本机验证的已通过项目。
